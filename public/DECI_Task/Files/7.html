Topic 12.2: The Evaluation Rubric

Exactly what the project is graded on, item by item, so you know precisely what you are being evaluated against.

⚖️ One Point or Zero
▼

This topic explains the rubric used to evaluate the project, so you know exactly what you are being graded on.

ℹ️
How Each Item Is Scored

Every item in the rubric receives one point if it was done correctly, and zero if it was not. There is no half point, and no item is scored on its own outside of this all-or-nothing rule.

📓 Rubric: Task 1
▼

For the first task, the rubric checks the following:

Notebook
The notebook was made in Google Colab with the correct name, and a text cell above it contains the name, ID number, and project name.
Loading
The dataset was loaded into a DataFrame with no error, along with a preview, the number of rows and columns, and the column names.
Description
A description of at least three sentences is present.
Sharing
Sharing is confirmed to be set to "Anyone with the link — can view."
🔬 Rubric: Task 2
▼

For the second task, the rubric checks the following:

Inspection
All checks were done — shape, column types, missing values, duplicates, and summary statistics — and every output is visible.
Problems Found
A text cell lists at least three real problems.
Duplicates
Duplicates were removed, along with the count.
City column
The city column is now standardised.
Missing values
Missing values were handled with an explained method.
Outliers
Q1, Q3, and IQR were calculated correctly, and the outliers were handled.
Clean file
The clean file StudentID-EgyptData-clean.csv was saved without an extra column, and without deleting the original file.
📊 Rubric: Task 3
▼

For the third task, the rubric checks the following:

Clean file loaded
The clean file was loaded.
Goals
At least three analysis goals are written before the analysis.
Pandas answers
Every goal was answered with pandas, with a sentence summarising it.
Charts
At least three charts are present, each with a title and labels, and each one a suitable chart type.
Summary
Three closing sentences are present: the biggest finding with a number, a detail, and a recommendation.
🏁 Rubric: Task 4
▼

For the fourth task, the rubric checks the following:

Insights
Two insights are present, each with an Observation, an Evidence with a number, and an Implication.
Hypotheses
Two hypotheses are present, written as questions, one after each insight.
Cells ran
All cells ran in order with no error.
Sharing
The notebook and the clean file were both shared, and both were submitted.
✅ Use It as a Checklist
▼
✅
Self-Check Before Submitting

Use this rubric as a checklist for yourself before you submit, to make sure every item has actually been done.

🚫
Plagiarism Check

Every submission goes through a plagiarism check. If any cheating is found, the project is given a zero and marked as a copied project.

  • Every rubric item is scored one point for correct, zero for incorrect — no half points, and the whole item must be right.
  • Task 1 is checked for correct notebook setup, error-free loading with a preview and shape, a three-sentence description, and correct sharing.
  • Task 2 is checked for a complete inspection, a "Problems Found" cell, duplicate removal, city standardisation, handled missing values, correctly calculated IQR outliers, and a properly saved clean file.
  • Task 3 is checked for loading the clean file, at least three goals, pandas answers with summaries, at least three labelled charts, and a three-sentence closing summary.
  • Task 4 is checked for two complete insights, two question-based hypotheses, an error-free full run, and both files shared and submitted.
  • Use the rubric as a self-checklist before submitting the project.
