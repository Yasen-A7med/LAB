Topic 11.3: Task 2 — Inspect and Clean the Data

The seven-step process for auditing digitamart_orders.csv, fixing what is broken, and saving a clean file ready for analysis.

🔬 The Heart of the Project
▼

Task 2 is inspecting the data and cleaning it. This task is the heart of the project, and it has seven steps that should be done in order.

ℹ️
Every Real Dataset Has Problems

Any real dataset arrives with problems. Your job is to discover those problems and fix them before building anything on top of the data.

🩺 The Full Inspection
▼
1 The Full Inspection

Inspect the whole dataset and display the output of every check. This step has five parts:

Shape
Look at the shape, so you know the number of rows and columns.
Types
Look at the type of each column, so you know whether numbers are actually stored as numbers.
Missing values
Count the missing values in every column.
Duplicates
Count the duplicates.
Summary statistics
Pull up the summary statistics to see the smallest and largest value, and the mean, for every numeric column.
📝 Naming the Problems
▼
2 Write Down the Problems

After inspecting, write a text cell titled Problems Found. List every real problem you found — at least three — each as one clear sentence.

✅
Evidence, Not Guesswork

This makes your cleaning plan grounded in something you actually saw in the inspection output, rather than a guess about what might be wrong.

🪞 Duplicates and Cities
▼
3 Duplicates

Duplicates are repeated orders — the same order recorded more than once. Find these duplicates and remove them. Print the number of rows before and after, so the number of removed orders is visible.

4 Standardise Cities

The city column contains the same city written in different forms — for example, different capitalisation, extra spaces, or abbreviations. Make every city name consistent, in the same form, then print the unique values to confirm each city now has exactly one spelling.

⚠️
Why This Matters for Grouping

You will group orders by city later on. If the names are not standardised, the same city will be counted as several different groups, and the totals will be wrong.

🕳️ Missing Values
▼
5 Missing Values

Missing values are information that is absent from the data. Find out where they are and how many there are. Choose a suitable method to fill them, and explain in a text cell why you chose that method.

Print the count of missing values before and after, so it is visible that they were actually handled.

📊 Outliers with IQR
▼
6 Outliers

Outliers are orders with a value that is very high and far from the rest of the orders. These can distort averages and charts later on. Use the IQR method to detect them.

💾 Saving the Clean File
▼
7 Save the Clean File

Once cleaning is finished, save the data into a new file named StudentID-EgyptData-clean.csv.

⚠️
Two Things to Avoid

Do not delete the original file, and do not add an extra numbering column when saving. This clean file is what you will work on in the next task.
